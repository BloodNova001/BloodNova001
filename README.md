## 📌 Featured Project

### 🧠 32-bit 5-Stage Pipelined RISC Processor

Designed a MIPS-like processor from scratch in Verilog.

**Key Concepts Implemented**

* Instruction pipelining (IF–ID–EX–MEM–WB)
* Control hazard handling (stall + NOP injection)
* Two-phase clock microarchitecture
* Behavioral memory model for verification
* Structured RTL ready for ASIC-style flow

📖 Detailed Design → `docs/architecture.md`
